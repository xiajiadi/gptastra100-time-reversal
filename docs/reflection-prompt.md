# 黑屏倒影素材提示词

下面是生成 `assets/reflect-1.jpg` 时使用的构图和材质要求。结尾素材 `reflect-2.jpg` 来自同一张图的轻微裁切，使房间与人物轮廓在首尾一致。

> 16:9 横向写实影像，只表现关闭显示器的防眩光玻璃上的微弱倒影，画面铺满，无屏幕边框、文字、图形或水印。凌晨三点的昏暗小公寓，左偏中的狭长高楼窗户外有几处冷灰蓝色灯光，玻璃上有雨滴。画面中央是一名双手横握手机、将手机挡在面前拍摄的人，仅见头肩黑色剪影。右侧半掩门的地面有一道细弱暖光。整体为深板岩蓝与近黑，反射柔和，带轻微灰尘和手机高感颗粒。窗光应保留足够层次，以便后续合成。避免亮灯、科幻灯效、清晰面部或第二个人影。

渲染时将图像映射到虚拟显示器表面，亮度、位移和可见度随相机角度及显示器状态变化。
